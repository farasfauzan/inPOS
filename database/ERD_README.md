## User Story: Alur RBAC

### Admin Flow:
```
1. Login dengan username 'admin'
   ↓
2. Session menyimpan: { role: 'admin' }
   ↓
3. Akses Halaman:
   - Dashboard    ✅
   - Products     ✅ (Add/Edit/Delete)
   - POS         ✅
   - Inventory   ✅ (Restock/Adjust)
   - Reports     ✅ (View/Export)
```

### Kasir Flow:
```
1. Login dengan username 'kasir'
   ↓
2. Session menyimpan: { role: 'kasir' }
   ↓
3. Akses Halaman:
   - Dashboard    → Redirect ke /pos
   - Products     → Redirect ke /pos (access denied)
   - POS         ✅ (Hanya ini yang boleh)
   - Inventory   → Redirect ke /pos (access denied)
   - Reports     → Redirect ke /pos (access denied)
```
